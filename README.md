# Mangalam HDPE Pipes Website

A modern, responsive industrial product showcase website built using pure HTML, CSS, JavaScript, and Tailwind CSS CDN.

This project includes:

- Product image carousel
- Zoom preview gallery
- Sticky navigation
- Mobile responsive navigation
- FAQ accordion
- Manufacturing process tabs
- Scroll reveal animations
- Modal system
- Responsive layouts
- Tailwind utility support

---

# 🚀 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Tailwind CSS (CDN)
